Project Overview:

This project focuses on developing a machine learning-based academic support system that predicts student performance and provides personalised learning recommendations. The main purpose is to help students understand their academic performance and identify learning resources that match their individual needs.

The system combines a machine learning prediction model with a personalised recommendation system. Students provide information about their study habits, previous academic performance, confidence levels, interests and learning goals. Based on this information, the application generates a predicted academic outcome, identifies potential academic risk and recommends suitable learning resources.

The complete system was developed using Python and Streamlit, providing an interactive web application where students can access their predictions, recommendations, suggested learning paths and academic insights.
